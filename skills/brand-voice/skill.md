# Brand Voice Skill

## Overview

This skill ensures all content matches our brand voice. Load this context whenever creating or reviewing content for any platform.

## Core Voice

For full voice guidelines, see `/docs/brandvoice.md`

Quick summary:
- Conversational, not corporate
- Direct, not wordy
- Practical, not theoretical
- Opinionated, not neutral

## Platform-Specific Rules

For full platform rules, see `/docs/platform-rules.md`

## Banned Words and Phrases

Always check output against `/docs/banned-words.txt`

## Content Principles

1. **Teach something** - Every post should leave the reader smarter
2. **Be specific** - Use real numbers, real tools, real timelines
3. **Take a stance** - Don't hedge. Say what you think
4. **Tell stories** - Real experiences beat abstract advice
5. **Be useful** - If someone can't act on it, cut it

## Writing Checklist

Before finalizing any content:
- [ ] Does it sound like a person, not a press release?
- [ ] Is the first line a hook?
- [ ] Did I use "AG" instead of "anti-gravity"?
- [ ] Are there any m-dashes? (Replace with regular dashes)
- [ ] Is it under the platform word/character limit?
- [ ] Would I actually post this on my own profile?
- [ ] Does it teach something or share an experience?
- [ ] Zero banned words from /docs/banned-words.txt?
